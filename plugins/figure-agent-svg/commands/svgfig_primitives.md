---
description: Render semantic SVG source from a figure primitive YAML layer.
---

Render generated scientific SVG fragments into `source/<name>.svg`.

**Usage**: `/svgfig_primitives <name>`

Run from `plugins/figure-agent-svg`.

This command reads:

```
examples/<name>/source/<name>.template.svg
examples/<name>/primitives.yaml
```

Then it replaces template comments of this form:

```
<!-- figure-agent-fragment:<fragment-name> -->
```

with semantic SVG generated by `scripts/svg_primitives.py`:

```
uv run python scripts/svg_primitives.py examples/<name>
```

The primitive layer is for reusable scientific figure fragments such as
`loglog_plot`, `polymer_chain`, and `energy_band`. It is not a traced-bitmap
path conversion layer. The generated source must still pass `/svgfig_export`
and `/svgfig_qa`.
