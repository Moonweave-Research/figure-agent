# Handcrafted-finish benchmark v1

This is a development benchmark, not a paper figure and not publication
evidence. It compares three visual treatments for one representative motif from
each current authoring baseline while preserving the scientific meaning.

## Motifs

1. **Amorphous trap host** — a bounded disordered polymer field with equal-size
   shallow/deep localized states embedded in the host.
2. **Progressive MIM transport** — matched device geometry under a held field;
   localized-state occupancy increases while the qualitative mobile-current cue
   weakens without becoming zero.
3. **Cantilever force sequence** — one finite-width clamped member near a drive
   electrode; neutral Maxwell attraction is subordinate to the opposing
   charge-mediated Coulomb result in the conditional reverse-bend state.

Each row contains a current-baseline grammar recreation, a freer LLM redraw,
and a restrained editorial refinement. The visible option ids mask those roles
inside the rendered board. The same Codex host authored and reviewed all three,
so the comparison is authorship-confounded and cannot create a human reward or
promote a learned rule.

## Physics invariants

- Each option within a motif preserves the same scientific claim; the benchmark
  varies visual treatment, not mechanism or state meaning.
- Repeated MIM geometry denotes matched cells under the same held-field
  condition; only the qualitative trapping occupancy and mobile-current cue
  change across the three internal states.
- The cantilever row compares opposing Maxwell-attraction and Coulomb-repulsion
  cues without asserting a measured force magnitude or a publication verdict.

## Review question

At full size and 50%/33% reduction, which option most clearly preserves object
identity and scientific hierarchy without relying on mechanical repetition,
random jitter, decorative texture, or extra explanatory prose?
