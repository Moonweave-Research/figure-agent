# CLAUDE.md - figure-agent-py

Claude Code entry point for the Python-first Fig1 semantic SVG plugin.

Use `skills/figure-agent-py/SKILL.md` as the workflow authority. This plugin
wraps `experiments/python_svg_semantic_fig1` and renders SVG/PNG from Python
scene payloads, scaffold contracts, and semantic verifiers. It is not the
TikZ/lualatex quality-kernel plugin.
